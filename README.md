## Public review setup

The review form is ready to use a real shared backend once you add your Supabase project credentials.

1. Create a Supabase project.
2. Run the following SQL in the SQL editor:

```sql
create table reviews (
  id bigint generated by default as identity primary key,
  name text not null,
  rating int not null check (rating between 1 and 5),
  comment text not null,
  created_at timestamptz default now()
);

alter table reviews enable row level security;

create policy "Public read access"
on reviews
for select
using (true);

create policy "Public insert access"
on reviews
for insert
with check (true);
```

3. Add your real values before the site script loads:

```html
<script>
  window.ICEMAX_SUPABASE_CONFIG = {
    url: 'https://YOUR_PROJECT_REF.supabase.co',
    anonKey: 'YOUR_SUPABASE_ANON_KEY',
    table: 'reviews'
  };
</script>
<script src="script.js"></script>
```

This keeps the reviews public and shared across visitors instead of storing them only in the browser.
